# 🎓 Student Affairs Management System  

A demo project for managing student affairs, built with **ASP.NET Core 7** following clean architecture principles.  

---

## 🚀 Features  
- User Authentication & Authorization (Identity with Role-Based Permissions)  
- JWT Authentication (Access, Refresh, and Revoke Tokens)  
- Full CRUD operations for Students (Insert / Update / Get All / Delete)  
- Subjects & Classes management  
- RESTful APIs with Swagger documentation  
- Repository Pattern & Onion Architecture  
- AutoMapper for object mapping  
- Dependency Injection  
- Distributed Lock for concurrency handling  
- CORS Configuration  
- Clean Code, SOLID principles, and Multi-Layer Architecture  

---

## 🛠️ Technologies  
- **ASP.NET Core 7**  
- **Entity Framework Core 7**  
- **Identity**  
- **JWT**  
- **Swagger / OpenAPI**  
- **AutoMapper**
